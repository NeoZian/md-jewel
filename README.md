# Md. Jewel — PhD Research Portfolio

A modern academic portfolio for AI/ML PhD outreach, research visibility, and GitHub Pages.

## Included

- `index.html` — single-page portfolio
- `assets/css/style.css` — responsive academic/portfolio styling
- `assets/js/main.js` — mobile navigation, section highlighting, subtle reveal effects, reading progress, and working back-to-top controls
- `assets/images/md-jewel.webp` — optimized profile image
- `assets/images/md-jewel.jpg` — profile image fallback / social preview
- `assets/images/favicon.svg` — site icon
- `assets/docs/Md_Jewel_PhD_CV.pdf` — current CV

## Design direction

The site is intentionally personal without becoming casual. It uses an editorial academic style, restrained motion, conversational first-person copy, and clear research hierarchy. Publication counts are not repeated in the profile card; visitors can see the work directly in the publication and manuscript sections.

## GitHub Pages deployment

1. Replace the files in the root of your existing GitHub Pages repository with the contents of this folder.
2. Commit and push the changes to GitHub.
3. In **Settings → Pages**, confirm GitHub Pages publishes from the correct branch/folder (usually `main` / root).
4. Wait for the Pages build to finish, then hard-refresh the live site.

No build step or package installation is required.
